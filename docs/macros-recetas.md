# Macros del catálogo de recetas

Los valores de **hidratos** y **grasas** añadidos al catálogo (`app/src/main/assets/recetas.json`) son **valores estimados** a partir de los ingredientes y tablas nutricionales estándar.

**Nota:** valores estimados, revisar con fuente fiable antes de publicar. No deben presentarse como datos oficiales. Las calorías y proteínas ya existentes en el catálogo siguen el mismo criterio de estimación.
